### 使用方式
1. 注册 rawg.io 获取 API Key
2. 创建 `scripts/rawg-config.json`：`{"apiKey": "你的key"}`
3. 运行 `node scripts/fetch-game.js "游戏名"`
4. 交互选择游戏 → 填写状态/评分 → 自动保存到 Obsidian vault
5. 运行 `bash scripts/sync-obsidian.sh` 同步到 Quartz

### 代理修复
- 问题：用户系统配置了代理 `http://127.0.0.1:7890`（Clash/V2Ray），curl 自动走代理但 Node.js `https.get` 不读取代理环境变量，导致请求超时
- 第一版修复：检测 HTTPS_PROXY/HTTP_PROXY 环境变量 → 仍然超时，因为用户 PowerShell 没有设置这些环境变量
- 根本原因：Windows 系统代理通过注册表设置（`HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings`，ProxyEnable=1, ProxyServer=127.0.0.1:7890），curl/浏览器读注册表，Node.js 不读
- 最终修复：fetch-game.js 新增 `getWindowsProxy()` 函数，用 `reg query` 读取注册表代理设置
  - `getProxy()` 优先级：环境变量 > Windows 注册表
  - 有代理时：HTTP CONNECT 隧道 + `tls.connect` 建立 TLS 连接 + 手动写 HTTP 请求
  - `parseHttpResponse()` 处理 chunked 编码
  - 无代理时：走原始 `https.get` 直连路径
  - 新增 import: `http`, `tls`, `execSync` (from child_process)
  - 启动时显示代理状态：`(代理已启用: 127.0.0.1:7890)` 或 `(直连模式，无代理)`
- 验证：搜索 + 详情获取全部成功（Elden Ring: Metacritic 95, FromSoftware, 62h）
- 注意：沙箱环境会阻止 TLS 握手，需用 `dangerouslyDisableSandbox` 运行；用户 PowerShell 不受此限制
