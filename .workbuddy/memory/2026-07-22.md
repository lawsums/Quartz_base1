# 2026-07-22 工作日志

## 番剧/漫画卡片系统实施

### 背景
用户有 Obsidian Bangumi 插件生成的番剧/漫画卡片数据（anime 44个 + manga 1个），需要转化为 Quartz 网站上的卡片展示页面。

### 完成内容

#### 新建 4 个文件
1. `scripts/generate-projects.js` — 数据提取脚本
   - 递归扫描 `content/projects/` 下所有 .md 文件
   - 解析 frontmatter（中文名、日文名、封面、观看状态、评分、标签等）
   - 数据清洗：封面 URL 提取、emoji 去除、数值 trim、标签拆分
   - Quartz slugify 路径生成（与 `@quartz-community/utils` 的 `slugifyPath` 一致）
   - 输出 `quartz/static/projects-index.json`

2. `quartz/static/project-query.js` — 前端渲染脚本
   - fetch JSON → 查找 `[data-project-query]` 占位 div → 渲染卡片
   - 支持 data-status / data-category / data-sort / data-order 属性筛选

3. `quartz/static/project-styles.css` — 卡片样式
   - 响应式网格 `grid-template-columns: repeat(auto-fill, minmax(160px, 1fr))`
   - 封面 3:4 比例、状态徽章、评分星级、悬停动画
   - 使用 Quartz 主题变量（`--light`/`--dark`/`--secondary`/`--lightgray`）自动适配暗色模式

4. `content/番剧库.md` — 展示页，分在看/想看/已看三个区域

#### 修改 3 个文件
1. `quartz/components/Head.tsx` — 在 `</head>` 前注入 project-styles.css 和 project-query.js
2. `package.json` — 添加 `generate-projects` 脚本，`prebuild` 增加 generate-projects 调用
3. `scripts/sync-leetcode.sh` → 改名 `scripts/sync-obsidian.sh` — 增加 Projects 目录同步 + JSON 生成

### 关键技术点
- Quartz slugify 规则：空格→`-`、`&`→`-and-`、`%`→`-percent`、`?`/`#`→删除、转小写
- Bangumi frontmatter 字段差异：anime 有集数/动画公司/开播年份，manga 有话数/出版社
- 观看状态 emoji：已看📘/想看⏰/在看📖，用 `\p{Extended_Pictographic}` 正则清除
- `prebuild` 脚本在 `npx quartz build` 前自动运行 generate-projects.js

### 验证结果
- JSON 生成：45 条目（44 anime + 1 manga），状态分布 已看27/想看16/在看2
- Build 成功：200 文件处理，817 HTML 输出
- 路径匹配：45/45 JSON 路径与生成的 HTML 文件完全匹配
- 静态资源全部可访问（HTTP 200）
- 本地预览服务器运行中（端口 8080）

### 数据流
```
Obsidian vault (Bangumi 插件)
  → robocopy → content/projects/
  → generate-projects.js → quartz/static/projects-index.json
  → Quartz build → public/static/projects-index.json
  → 浏览器 fetch JSON → project-query.js 渲染卡片
```
